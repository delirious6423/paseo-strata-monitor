Shows live status of a local Strata inference server and starts or stops it. A sidebar row is always visible and shows decode and prefill tokens per second (the last request's speeds when idle); clicking it opens a screen with a speed graph, request state and queue, GPU and memory use, and recent requests.

The daemon reads Strata's `/metrics` endpoint once per poll and shares that result between open clients. Polling runs only while the screen is open, every second while a request is running and every three seconds otherwise.

By default the daemon tries `http://127.0.0.1:8080` and then `http://127.0.0.1:8093`. Set `STRATA_URL` in the daemon environment to use another address, and `STRATA_API_KEY` if the server needs a bearer token. Only the Strata server's own metrics are read; nothing is sent elsewhere.

The screen's Engine card lists the Strata models found on the daemon machine. Pick one and press Load; the card shows loading time and turns ready when the server answers. Abort cancels a load and Stop ends a running engine, freeing GPU and RAM. Loading a model stops any other Strata engine first. Control requires Linux with Strata installed as user systemd services. The model list comes from a registry file (`STRATA_MODELS`, a JSON list of id, label, service unit, port and a short note shown under the picker); without one, it uses `strata@<model>` for each `run-<model>.sh` in `STRATA_ROOT` (default `/mnt/data4tb/Strata-new`) and optionally `strata-exl3-quality.service`. The plugin only starts or stops those units.
